    Creating Content

    Rooms

    Create a Room

    1. Create → IFEngine/Kinds/Room
    2. Set Main Name (how player sees it)
    3. Set Initial Appearance (first visit description)
    4. Add Aliases (e.g., "kitchen", "room")

    Connect with Exits

    1. Create → IFEngine/Kinds/Exit
    2. Set Main Name to direction ("north", "upstairs")
    3. Assign Destination Room
    4. Add Exit to source room's Exits list

    Add a Door

    1. Create → IFEngine/Kinds/Door
    2. Configure Openable and Lockable properties
    3. Assign Door to the Exit

    Items

    Basic Item

    1. Create → IFEngine/CoreObjects/BaseObject
    2. Set name and appearance
    3. Add to a room's HoldsContents property

    Container

    1. Create → IFEngine/Kinds/Container
    2. Add items to its HoldsContents
    3. Configure Openable if needed

    Key

    1. Create a BaseObject for the key
    2. On the locked door, set Lockable.Key to your key asset

    Characters

    Player

    1. Create → IFEngine/Kinds/Creature
    2. Check Is Player
    3. Assign to Orchestrator's Player Character

    NPCs

    1. Create Creature assets
    2. Add to rooms via HoldsContents
    3. Add to Orchestrator's Non Player Characters

    Tips

    • Use Initial Appearance for atmospheric first impressions
    • Add Text Responses for "examine" to give item details
    • Use Action Restrictions to block illogical actions
    • Test frequently with help to verify commands work
